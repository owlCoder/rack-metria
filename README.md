# RackMetria

Simulation of data center IT, power, cooling, and network infrastructure.

Course: Information Security of Infrastructure Systems, Faculty of Technical Sciences, University of Novi Sad.

## Scope

- Configure rooms, thermal zones, racks, equipment, and infrastructure connections.
- Model server load, power distribution, UPS batteries, and temperature changes.
- Track service availability, telemetry, alarms, and event history.
- Simulate failures and security incidents, then compare scenario results.

## Architecture

The specification requires Clean Architecture and SOLID principles. IT, power, cooling, and network models are separate from the simulation orchestrator, storage, and user interface.
